# shadinotatech.com

Website of Shadinota Tech (CardCraft – ID Card Maker, InvoiceAtlas), privacy policies and app-ads.txt.
Hosted on Cloudflare Pages at https://shadinotatech.com (no build step, output directory = root).
Also served by GitHub Pages at https://shadinotatech.github.io.

To add an app: copy one `<article class="app">` block in index.html and change the name, icon, screenshots and Google Play link.
